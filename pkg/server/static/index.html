How it works

1

Pick a name

Search for an available subdomain. Names can be 1 to 63 characters long and must follow standard domain syntax.

2

Open a PR

Configure your record (CNAME, A, AAAA, TXT or NS). The portal generates a JSON file and opens a pull request on GitHub.

3

Deploy

Once merged, CI compiles RFC 1035 zone files and reloads CoreDNS across all edge nodes in under 5 seconds.
