Free subdomains for developers.

Free, persistent *.be-a.dev subdomains for your websites, bots, and APIs. Maintained in a public GitHub repo, backed by CoreDNS across European edge servers.

.be-a.dev

How it works

Each subdomain is defined by a single JSON file under domains/be-a.dev/<first-letter>/<name>.json in the repository. To claim or update a domain, submit a Pull Request. CI validates your records and upon merge, changes go live globally within seconds.

domains/be-a.dev/a/alex.json
{
  "owner": {
    "username": "alex"
  },
  "records": {
    "CNAME": "alex.github.io."
  }
}

Supported records

CNAME Point to GitHub Pages, Vercel, Fly.io, Cloudflare, etc. (must end with a dot).
A Direct IPv4 addresses of your server or VPS.
AAAA IPv6 addresses for modern dual-stack routing.
TXT Verification tokens, ACME challenges, or SPF records.
NS Delegate DNS management of your subdomain to your own nameservers.
