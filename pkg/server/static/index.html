Free subdomains for developers.

Persistent *.be-a.dev subdomains for your websites, bots, and APIs. Maintained via GitOps in a public GitHub repository, backed by authoritative CoreDNS edge nodes.

.be-a.dev

How it works

Each subdomain is defined by a single JSON file under domains/be-a.dev/<letter>/<name>.json. Submit a Pull Request with your configuration. When merged, CI validates your records and syncs changes globally within seconds.

domains/be-a.dev/a/alex.json
{
  "owner": {
    "username": "alex"
  },
  "records": {
    "CNAME": "alex.github.io."
  }
}

Supported records

CNAME Point to GitHub Pages, Vercel, Fly.io, Cloudflare, etc. (must end with a dot).
A Direct IPv4 addresses of your server or VPS.
AAAA IPv6 addresses for modern dual-stack routing.
TXT Verification tokens, ACME challenges, or SPF records.
NS Delegate DNS management of your subdomain to external nameservers.
